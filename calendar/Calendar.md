# Calendar

Live view of dated notes in `calendar/`, sourced from their frontmatter.
See `calendar/AGENTS.md` for the field schema.

![[calendar/Calendar.base]]

The **Calendar Frontmatter** plugin (`.obsidian/plugins/calendar-frontmatter/`)
also renders a monthly grid; open it from the ribbon or the command palette
("Open Calendar (Frontmatter)"). Opening this note auto-opens that view.
